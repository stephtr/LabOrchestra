# Brief: update laborchestra.com for the new LabOrchestra

For the assistant that builds and edits the website (static `index.html`, `style.css`, `script.js`, `img/`, plain HTML/CSS/JS, no build step).
Read this whole file first, then change only what it lists. Keep the existing tone: plain, short sentences, concrete, no hype.

## 0. Ground rules

- **Honesty is the main constraint.** The site tells labs what exists. Three states must stay apart:
  1. *Runs in our lab today*: the **previous version** (what the Nature Physics experiment used).
  2. *Built and tested without hardware*: the **new version** (the rewrite, first public release December 2026). Tested with simulated instruments and automated tests on Windows, Linux and macOS. **Not yet run against the real instruments in our lab** (PicoScope, SmarAct, R&S SMA100B drivers are untested on hardware; the 200 MB/s load test of the new pipeline is still to do).
  3. *In development / planned*.
- Every screenshot below shows **simulated instruments** (the demo workspace). Captions must say so. Never write "our experiment" under them.
- Do not add claims, numbers, customer names, benchmarks or dates that are not in this file or already on the page.
- Keep: licence statement (GPL-3.0 server and client; the SDKs are Apache-2.0, say this only if you add a licence detail), the December 2026 release date, the contact form, Impressum and Privacy pages untouched.
- Light/dark: the site already follows `prefers-color-scheme`. Each screenshot exists in both schemes. Use `<picture>` with `<source media="(prefers-color-scheme: dark)">`, as the logo does.
- Performance: images are WebP, 2000 px wide (shown at about 1000 px, so sharp on 2x screens), 20-85 KB each. Use `width`/`height` attributes (2000 x 1194), `loading="lazy"` except the hero, and meaningful `alt` text (describe what is visible, not "screenshot").
